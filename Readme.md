## ⚡ Portfolio Architecture & Features

- **Blazing Fast Modern Stack**: Powered by **Vite 6** and **React 18** with instant Hot Module Replacement (HMR) and optimized Rollup code-splitting chunks.
- **Strict Type Safety**: TypeScript with strict mode enabled, zero `any` shortcuts, and automated type validation.
- **Accessible & Responsive Design**: WCAG 2.2 AA compliant with semantic HTML, keyboard navigation, clean contrast ratios, and dark/light mode toggle.
- **Interactive Classic Tech Stack**: Real-time filtering across backend, frontend, cloud, data, and devops with authentic classic Devicon brand assets.
- **Zero Scrollbar Polish**: Filter pills feature responsive wrap-around flex layouts, preventing disruptive browser scrollbars across all screen widths.
- **Self-Hosted High-Efficiency Assets**: All images and icons are compressed WebP/SVG assets hosted locally within `public/img/` for instantaneous first-contentful paint.
- **Verified Technical Projects**: Card inspector detailing real architecture flows, performance constraints, and verified live deployments.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/Mohitur669/Portfolio.git

# Navigate into the project directory
cd Portfolio

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application with Hot Module Replacement.

### Running Unit Tests

```bash
npm test
```
Executes the Vitest test suite verifying project link validity, credential integrity, and data topology.

### Production Build

```bash
npm run build
```
Typechecks the application (`tsc`) and compiles optimized production bundles into the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
Spins up a local web server serving the compiled `dist/` assets to test production behavior.
